## Added

- Fingerprinting resistance for canvas, text measurement, WebGL, audio and
  processor cores. Each site reads a slightly different value, so the picture
  never adds up.
- A clean start page with no sponsored tiles, no promos and no "trending"
  panel.
- Local import of bookmarks and passwords on first run.

## Removed

- Every telemetry endpoint.
- Firefox Sync, along with the account system and the cloud profile behind it.
- Sponsored shortcuts and the new-tab promotional content.

## Fixed

- The window controls no longer inherited the wrong colour in the dark themes.
- Tabs kept their position after a restart.
